GENERADOR DE ALUMNOS (Bases de Datos II)
Creador: Gerardo Tapia F.

Este proyecto es una herramienta que genera inserciones de alumnos en distintos formatos (mysql, postgre, CSV, JSON). Esta compuesto en html, javascript y su estilo es css.

Funciona simplemente abriendo el index (generador.html) y seleccionando la cantidad de alumnos que se desea generar, tambien se selecciona el formato y se tiene la opción de descargar el insert.
